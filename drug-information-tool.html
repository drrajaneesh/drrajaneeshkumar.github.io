Drug Information Search

Indications, dosage, contraindications and side effects from FDA-approved labels. Searches an offline set instantly, then live FDA labels.

For use by healthcare professionals. This tool supports, and is not a substitute for clinical judgement. Verify against the full prescribing information and your local formulary before prescribing. Search terms go only to the public sources named below; nothing else is stored or transmitted.

Limits: text is the United States (FDA) label as published, so doses, approved indications and warnings can differ in Bahrain, the GCC, the EU and India. The offline set holds drugs; everything else needs a live connection. Side-effect and indication searches match label wording, so try a second synonym. Renal, hepatic, paediatric and pregnancy dosing sit inside the Dosage section; use the quick-find buttons. Long sections may be shortened offline; the link under each label opens the full text.

Sources: openFDA Drug Label (U.S. FDA; openFDA states its data are unvalidated and not for medical care decisions); DailyMed (U.S. National Library of Medicine). Brand names via RxNorm (U.S. National Library of Medicine). Offline set built .
